# 6258-soc-resposta-incidentes

Detectar um incidente é apenas metade do trabalho. A outra metade é saber o que fazer depois que a detecção acontece: conter o dano, erradicar a ameaça, recuperar os sistemas afetados e garantir que tudo isso seja feito de forma ordenada, documentada e eficaz. Resposta a incidentes é uma disciplina com metodologia própria, e profissionais que a dominam são dos mais valorizados no mercado de segurança.

Este curso cobre o ciclo completo de resposta a incidentes com foco no que um analista de SOC N1 e N2 precisa saber fazer na prática. Você vai aprender as fases do ciclo de resposta, como conduzir contenção e erradicação para os tipos de incidente mais comuns, como se comunicar durante uma crise e como documentar o processo de forma que a organização aprenda com cada evento. O curso inclui simulações de incidentes reais para que você chegue ao mercado com experiência prática, não apenas teoria.

* * *

## 📋 Sobre o Curso

Este curso capacita profissionais para atuar na resposta a incidentes de segurança cibernética. São 24 vídeos distribuídos em 6 aulas, totalizando aproximadamente 6 horas de conteúdo prático.

O diferencial está nos laboratórios: você não apenas assiste, você executa. Cada aula tem exercícios práticos com máquinas virtuais Windows e Linux, scripts Python e PowerShell, simulações realistas de ataques e ferramentas profissionais.

* * *

## 🎯 Objetivos de Aprendizagem

Ao final do curso, você será capaz de:

- Descrever as fases do ciclo de resposta a incidentes (NIST SP 800-61 e PICERL)
    
- Conduzir triagem e priorização de alertas usando critérios objetivos
    
- Executar procedimentos de contenção, erradicação e recuperação
    
- Construir e seguir runbooks e playbooks para cenários padronizados
    
- Comunicar o status de um incidente para diferentes públicos
    
- Documentar incidentes gerando relatórios profissionais
    
- Conduzir análise de causa raiz com Modelo Diamante e 5 Porquês

## 🚀 Instalação Rápida

1.  Instale o VirtualBox e o Vagrant
    
2.  Clone este repositório
    
3.  Copie o `Vagrantfile` para um diretório de trabalho
    
4.  Execute `vagrant up`
    
5.  Siga os scripts de instalação em `scripts/`
